# zhenxun-plugin-groupmate-waifu (娶群友)

基于 NoneBot2 和 真寻 Bot (Zhenxun) 开发的群聊互动娱乐插件。
在原版的基础上，深度重构了“分手/离婚”的经济惩罚与防滥用机制，增加了小黑屋和全局 Ban 系统对接，让群内的“渣男/渣女”无处遁形！

## ✨ 功能特性

*   **👥 随机/指定结婚：** 每天可以随机抽取一名群友作为老婆/老公，或者直接 `@某人` 强势表白（附带 NTR 机制）。
*   **🔞 涩涩互动：** 支持对群友或自己的 CP 进行“透群友”操作，拥有独立的成功率和好感度判定。
*   **💰 硬核分手经济学（核心优化）：**
    *   **和平分手：** 正常离婚有概率和平收场，好聚好散。
    *   **财产纠纷：** 离婚失败将引发财产纠纷，随机扣除双方中一人的 10%~50% 金币作为补偿，并抽取 5% 手续费。
    *   **闪离严惩 (渣男/渣女判定)：** 主动表白成功后，**5 分钟内**立马提分手的，直接扣除主动方 50% 个人总资产赔偿给对方（扣除 5% 手续费）。
*   **🚔 连环闪离入狱系统：** 当天累计触发 3 次恶意闪离，不仅全额扣款，还会被直接关入插件小黑屋 120 分钟，同时**联动 Zhenxun 底层 Ban 系统**，将该用户全局/群组拉黑 120 分钟。
*   **📊 数据可视化：** 提供精美的图片化卡池查看和本群 CP 列表。

## 🚀 安装与依赖

将本插件文件夹直接放入 Zhenxun Bot 的 `plugins` 目录下即可。

**依赖项：**
本插件使用了 `pil_utils` 进行图片生成。如果你的环境中尚未安装，请通过终端进行安装：
```bash
uv pip install pil_utils
```
*(如果是新环境初始化，也可将其加入依赖配置后执行 `uv sync`)*

## 💬 指令说明

所有指令均支持携带命令前缀（如 `/`、`.` 或不带前缀）。

| 指令 | 说明 |
| :--- | :--- |
| `娶群友` | 随机抽取一位今天还没对象的人结婚 |
| `娶群友 @某人` | 指定和某人结婚，有概率失败或牛头人(NTR) |
| `透群友` / `透群友 @某人` | 涩涩小游戏，对象有概率拒绝 |
| `离婚` / `分手` | 终结当前的 CP 关系（附带硬核经济结算和防闪离机制） |
| `查看群友卡池` | 生成图片，查看当前群内还是单身的群友列表 |
| `本群cp` | 生成图片，查看当前群内已经配对成功的 CP 列表 |

## ⚙️ 配置说明

你可以在插件目录下的 `config.py` 中自由调整各个事件的概率和经济参数。

```python
from pydantic import BaseModel, Extra

class Config(BaseModel, extra=Extra.ignore):
    # --- 冷却与重置 ---
    waifu_cd_bye: int = 3600       # 分手命令的冷却时间（秒），默认 1 小时
    waifu_save: bool = True        # 是否保存数据
    waifu_reset: bool = True       # 是否每天零点重置 CP 关系

    # --- 概率配置 (1-100) ---
    waifu_he: int = 65             # 娶群友成功率 (65%)
    waifu_be: int = 35             # 娶群友失败率 (35%)
    waifu_ntr: int = 80            # 尝试娶别人老婆时的 NTR 成功率 (80%)
    yinpa_he: int = 15             # 涩涩陌生人成功率 (15%)
    yinpa_be: int = 60             # 涩涩陌生人失败率 (60%)
    yinpa_cp: int = 65             # 涩涩自己老婆的成功率 (65%)

    # --- 经济与惩罚配置 ---
    waifu_fee_ratio: float = 0.05          # 分手扣款时的系统手续费比例 (默认 5%)
    waifu_punish_min_ratio: float = 0.10   # 正常分手触发财产纠纷时，随机扣款下限 (默认 10%)
    waifu_punish_max_ratio: float = 0.50   # 正常分手触发财产纠纷时，随机扣款上限 (默认 50%)

# 正常分手的和平概率
BREAKUP_SUCCESS_RATE = 0.7  # 70% 概率和平分手，30% 概率触发财产纠纷
```

## 📝 逻辑更新细节

*   **@ 机制优化：** 所有的经济变动播报不再使用模棱两可的“你”和“对方”，均采用 `MessageSegment.at()` 强艾特当事人，消除群聊视角歧义。
*   **状态修正：** 修复了原版插件中，当用户单身/失败时再次请求娶特定群友，会报出“你的 CP 是你自己”的错误显示。
*   **跨文件系统调用：** 深度对接了 Zhenxun 的 `UserConsole` (金币结算) 与 `BanConsole` (系统级拉黑)，实现了生态闭环。
